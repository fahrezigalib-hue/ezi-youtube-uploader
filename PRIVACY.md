# Privacy Policy — Ezi YouTube Uploader
Last updated: 26 November 2026
Ezi YouTube Uploader is a personal, single-owner tool. It is used only by its owner to upload and schedule videos to the owner's own YouTube channels through the official YouTube Data API v3.
Data the tool accesses: YouTube channel information and video metadata of the owner's own channels, via OAuth 2.0 authorization granted by the owner.
Data storage: OAuth refresh tokens are stored only on the owner's own private server. No data is sold, shared, or transferred to any third party. No data is collected from any other person.
Data deletion: the owner can revoke the tool's access at any time from the Google Account permissions page, which invalidates the stored tokens.
